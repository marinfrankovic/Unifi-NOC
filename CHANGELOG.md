# Changelog

## 1.0.0

First public, noncommercial source-available release.

- UI-driven owner/controller setup with encrypted profiles and verified TLS.
- Site-scoped accounts, default-deny permissions and preserved monitoring selections.
- Site/WAN/SD-WAN monitoring, capability-aware health and explicit freshness/coverage.
- Device, port, wireless/client telemetry; topology, events and configuration changes.
- Linked history charts, missing-data gaps, availability, maintenance and attention views.
- Fullscreen wallboard, ntfy/Telegram notifications and owner diagnostics.
- Unacknowledged-only sidebar alert badge; acknowledgements preserve firing conditions/history.
- Portable Docker deployment, persistent volumes, backup helpers and public operational guides.
- Synthetic screenshots, GitHub Pages, privacy checks and versioned image publishing.

See [GitHub releases](https://github.com/marinfrankovic/Unifi-NOC/releases) for published versions and image readiness.
